👤 Account

A key signs a device in without a password — send it as Authorization: Bearer …, or ?key=… where headers aren't possible. Revoking one takes effect immediately.

👥 User accounts

Server Admin — runs the machine: everything below, plus the Log card, and the only role that can grant or change this one.
Admin — full access, including the Config dialog, the power button, and these accounts.
Edit — adds and removes library folders, channels, mounts, playlists and streams, but can't reach the Config dialog or accounts.
Read — watches what's been shared, and nothing else.
