Media library

Add a library folder — movies, music, and pictures inside it become playable here.

Live channels

👤 Account

A key signs a device in without a password — send it as Authorization: Bearer …, or ?key=… where headers aren't possible. Revoking one takes effect immediately.

👥 User accounts

Administrators can configure the server, start and stop it, and manage accounts. Everyone else can watch what's in the shared library and nothing more.
